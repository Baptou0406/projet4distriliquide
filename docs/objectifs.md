# Introduction

Le projet **Mix&Go** consiste à concevoir un distributeur automatique de liquides. L’objectif est de créer un système capable de doser et de distribuer plusieurs liquides dans des verres, de manière simple, propre et automatisée.

Ce projet regroupe plusieurs domaines : la conception mécanique, l’impression 3D, l’automatisation, l’intégration de composants et la documentation technique.

## Contexte du Projet

Dans le cadre du projet **I3 FISA PAUC S6 2025-2026**, notre équipe doit concevoir et réaliser un prototype fonctionnel autour d’un système de distribution de liquides.

L’idée est de créer un dispositif capable de positionner des verres, puis de distribuer automatiquement un ou plusieurs liquides grâce à des réservoirs et des pompes. Le système doit être pensé pour être compact, stable, compréhensible et facilement améliorable.

## Objectifs du Projet

Les principaux objectifs du projet sont :

* concevoir un système de distribution automatique de liquides ;
* utiliser un plateau tournant pour positionner plusieurs verres ;
* intégrer plusieurs réservoirs afin de distribuer différents liquides ;
* commander les pompes pour contrôler la distribution ;
* automatiser le fonctionnement global du système ;
* obtenir une structure stable et propre ;

# Existant

Il existe déjà des distributeurs automatiques de boissons et des systèmes de dosage de liquides dans l’industrie ou dans le commerce. Cependant, ces solutions sont souvent complexes, coûteuses ou peu adaptées à un projet de prototypage.

Notre objectif est donc de créer une version plus simple et accessible, adaptée à nos moyens de fabrication. Le projet repose sur une structure mécanique, des pièces imprimées en 3D, des réservoirs, des pompes et une partie automatisée.

# Cahier des Charges

Le système doit respecter plusieurs contraintes :

* être capable de distribuer plusieurs liquides ;
* permettre le positionnement de plusieurs verres ;
* être suffisamment compact pour limiter l’encombrement ;
* rester stable pendant le fonctionnement ;
* intégrer les pompes et les réservoirs dans une structure propre ;
* permettre une automatisation progressive ;
* faciliter la maintenance et les modifications ;
* être documenté sur le site du projet.

À terme, le projet devra permettre l’ajout de capteurs de position afin de vérifier la présence des verres et d’améliorer la précision du fonctionnement.
